🎯 Maqsad

Bu loyiha — real klinika yoki shifohonani raqamlashtiradigan backend tizim. Hozirgi kunda ko'plab klinikalarda hamma narsa qog'ozda: bemor daftari, shifokor jadvali, retsept varaqalari, to'lov cheki. Bu tizim o'sha jarayonlarning hammasini kompyuterga o'tkazadi va avtomatlashtiradi.

Oddiy qilib aytganda: bemor klinikaga kirganidan chiqib ketguniga qadar bo'lgan hamma narsa — bitta tizimda, real vaqtda, hech qanday qog'ozsiz.

Menga qiziq tomoni: Bu tizim aslida uchta alohida "dunyo"ni birlashtiradi — adminstratsiya, shifokor va bemor. Har birining o'z ko'rinishi va imkoniyati bor, lekin ular bitta bazadan ma'lumot oladi. Bu arxitektura — ko'pchilik real tibbiy tizimlarning asosiy g'oyasi.

👥 Tizimda kimlar bor?

Adminstratsiya (reception): Klinikaning "eshigi". Ular bemorlarni ro'yxatga oladi, shifokorga yuboradi, shifokordan kelgan retseptni qabul qiladi va to'lovni oladi. Adminstratsiyada ikkita asosiy ko'rinish bor:

1-ko'rinish: Yangi kelgan bemorlar — kim keldi, nima kasali bor, qaysi shifokorga yuborish kerak. Bu yerda admin shifokorlarni ko'rib, bemor kasalligiga mos bo'sh shifokorni tanlaydi va yozadi.

2-ko'rinish: Shifokordan javob kelgan bemorlar — shifokor ko'rib bo'ldi, tashxis qo'ydi, dorilarni belgiladi, narxini yozdi va adminstratsiyaga yubordi. Endi bemor to'lov qilishi kerak.

Shifokor (doctor): Klinikaning mutaxassisi. U o'ziga yuborilgan bemorlar ro'yxatini ko'radi. Bemor bilan gaplashib, tekshirib, tashxis qo'yadi va dorilarni belgilaydi. Hammasi tugagach, bu ma'lumotlarni adminstratsiyaga yuboradi — bemor to'lov qilganidan keyin retseptni oladi.

Bemor: Klinikaga kelib, adminstratsiyaga ism-familiyasi, telefoni, kasalligini aytadi. Adminstratsiya tomonidan tegishli shifokorga yo'naltiriladi. Shifokordan konsultatsiya olib, retseptni to'lov orqali qo'lga kiritadi.

🏗️ Nima uchun bu arxitektura?

Kodni yozishda men uchta qoidaga amal qildim:

Model = faqat ma'lumot qolip. model.js faylida faqat Mongoose schema bo'ladi. Hech qanday bcrypt, hech qanday jwt, hech qanday mantiq. Faqat "bu ma'lumot qanday ko'rinishda saqlansin" degan javob.

Controller = barcha mantiq. bcrypt bu yerda hash qiladi, jwt bu yerda token yaratadi, ma'lumot tekshirish ham shu yerda. Qo'shimcha fayl (utils, helpers) kerak emas — hammasini to'g'ridan controller da qilish ancha tushunarliroq.

Middleware = darvoza. Himoyalangan route ga so'rov kelganda avval middleware tekshiradi: "Bu odam login qilganmi? Uning roli to'g'rimi?" Shundan keyingina controller ishlaydi.

Mening fikrim: Ko'p dasturchilar "utils" va "helpers" papkalari yaratib, kodni tarqoq qilib yuborishadi. Men bu loyihada hamma narsani controller da qoldirdim — bu kodni o'qiyotgan odam uchun ancha qulay, chunki bitta faylda hamma mantiqni ko'radi.

🔐 JWT token qanday ishlaydi?

1

Login qilish

Admin email + parol yuboradi. bcrypt parolni tekshiradi. To'g'ri bo'lsa — ikkita token yaratiladi.

2

accessToken — 15 daqiqa

Har bir so'rovda Authorization: Bearer TOKEN header da yuboriladi. 15 daqiqadan keyin eskiradi.

3

refreshToken — 7 kun, DB da saqlanadi

Access token eskirganda — frontend bu tokenni /api/auth/refresh ga yuboradi va yangi access token oladi.

4

Logout

DB dagi refreshToken null ga o'zgaradi. Endi hech kim bu token bilan yangi access ola olmaydi.

Auth Controller
bcrypt va JWT — faqat shu yerda
📄 src/controllers/auth.controller.jsyangilash
Nima uchun bu yerda? bcrypt.hash(), bcrypt.compare(), jwt.sign(), jwt.verify() — barchasi shu bir faylda. Boshqa hech qayerda yo'q. Tushunish oson, topish oson.
const bcrypt = require('bcrypt');       // parol hash uchun
const jwt    = require('jsonwebtoken');  // token uchun
const User   = require('../models/user.model');

// ─── REGISTER ─────────────────────────────────────────────────────────────
const register = async (req, res) => {
  try {
    const { name, email, password, role } = req.body;

    // 1. Email allaqachon borligini tekshir
    const exists = await User.findOne({ email });
    if (exists) return res.status(400).json({ message: 'Bu email allaqachon bor' });

    // 2. Parolni bcrypt bilan hash qilish (10 = murakkablik darajasi)
    const hashedPassword = await bcrypt.hash(password, 10);

    // 3. Foydalanuvchini yaratish
    const user = await User.create({ name, email, password: hashedPassword, role });

    res.status(201).json({
      success: true,
      data: { _id: user._id, name: user.name, email: user.email, role: user.role }
    });
  } catch (err) { res.status(500).json({ message: err.message }); }
};

// ─── LOGIN ─────────────────────────────────────────────────────────────────
const login = async (req, res) => {
  try {
    const { email, password } = req.body;

    // 1. Userni topish
    const user = await User.findOne({ email });
    if (!user) return res.status(401).json({ message: 'Email yoki parol xato' });

    // 2. Parolni tekshirish — kirgan parolni DB dagi hash bilan solishtiradi
    const isMatch = await bcrypt.compare(password, user.password);
    if (!isMatch) return res.status(401).json({ message: 'Email yoki parol xato' });

    // 3. Access token — 15 daqiqa — har bir so'rovda header da yuboriladi
    const accessToken = jwt.sign(
      { id: user._id, role: user.role },
      process.env.ACCESS_TOKEN_SECRET,
      { expiresIn: '15m' }
    );

    // 4. Refresh token — 7 kun — DB da saqlanadi, yangi access olish uchun
    const refreshToken = jwt.sign(
      { id: user._id },
      process.env.REFRESH_TOKEN_SECRET,
      { expiresIn: '7d' }
    );

    // 5. Refresh tokenni DB ga yozish
    user.refreshToken = refreshToken;
    await user.save();

    res.json({
      success: true,
      data: { _id: user._id, name: user.name, role: user.role, accessToken, refreshToken }
    });
  } catch (err) { res.status(500).json({ message: err.message }); }
};

// ─── REFRESH — access token eskirganda yangi olish ────────────────────────
const refresh = async (req, res) => {
  try {
    const { refreshToken } = req.body;
    if (!refreshToken) return res.status(401).json({ message: "Token yo'q" });

    // Refresh tokenni verify qilish
    let decoded;
    try {
      decoded = jwt.verify(refreshToken, process.env.REFRESH_TOKEN_SECRET);
    } catch {
      return res.status(403).json({ message: 'Token yaroqsiz yoki eskirgan' });
    }

    // DB dagi token bilan solishtirish (o'g'ri ishlatmasligi uchun)
    const user = await User.findById(decoded.id);
    if (!user || user.refreshToken !== refreshToken)
      return res.status(403).json({ message: 'Token mos kelmadi' });

    // Yangi access token
    const newAccessToken = jwt.sign(
      { id: user._id, role: user.role },
      process.env.ACCESS_TOKEN_SECRET,
      { expiresIn: '15m' }
    );

    res.json({ success: true, data: { accessToken: newAccessToken } });
  } catch (err) { res.status(500).json({ message: err.message }); }
};

// ─── LOGOUT ────────────────────────────────────────────────────────────────
const logout = async (req, res) => {
  try {
    // req.user — middleware dan keladi
    await User.findByIdAndUpdate(req.user._id, { refreshToken: null });
    res.json({ success: true, message: 'Chiqdingiz' });
  } catch (err) { res.status(500).json({ message: err.message }); }
};

module.exports = { register, login, refresh, logout };

Nima uchun? Admin bemorni ro'yxatga oladi, qidiradi, ko'radi. ?status=kutmoqda — 1-navbat (shifokorga yuborilmaganlar). ?status=yozilgan — shifokorga yuborilganlar.
const Patient = require('../models/patient.model');

// Yangi bemor qo'shish — admin yozadi
const addPatient = async (req, res) => {
  try {
    const { fullName, phone, birthDate, gender, illness, specialty } = req.body;

    if (!fullName || !phone || !illness || !specialty)
      return res.status(400).json({ message: 'fullName, phone, illness, specialty majburiy' });

    const patient = await Patient.create({ fullName, phone, birthDate, gender, illness, specialty });
    res.status(201).json({ success: true, data: patient });
  } catch (err) { res.status(500).json({ message: err.message }); }
};

// Barcha bemorlar ro'yxati
// ?status=kutmoqda  →  1-navbat: shifokorga yuborilmaganlar
// ?status=yozilgan  →  shifokorga yuborilganlar
// filter yo'q      →  hammasi
const getAllPatients = async (req, res) => {
  try {
    const filter = req.query.status ? { status: req.query.status } : {};
    const patients = await Patient.find(filter).sort({ createdAt: -1 });
    res.json({ success: true, count: patients.length, data: patients });
  } catch (err) { res.status(500).json({ message: err.message }); }
};

// Bitta bemor
const getPatient = async (req, res) => {
  try {
    const patient = await Patient.findById(req.params.id);
    if (!patient) return res.status(404).json({ message: 'Bemor topilmadi' });
    res.json({ success: true, data: patient });
  } catch (err) { res.status(500).json({ message: err.message }); }
};

// Ism yoki telefon bo'yicha qidirish — ?q=Alisher yoki ?q=901234567
const searchPatient = async (req, res) => {
  try {
    const q = req.query.q;
    if (!q) return res.status(400).json({ message: 'q parametri kerak' });

    const patients = await Patient.find({
      $or: [
        { fullName: { $regex: q, $options: 'i' } },
        { phone:    { $regex: q, $options: 'i' } },
      ]
    });
    res.json({ success: true, count: patients.length, data: patients });
  } catch (err) { res.status(500).json({ message: err.message }); }
};

module.exports = { addPatient, getAllPatients, getPatient, searchPatient };

const getDoctorsBySpecialty = async (req, res) => {
  try {
    const { specialty, date } = req.query;
    if (!specialty) return res.status(400).json({ message: 'specialty kerak' });

    const doctors = await Doctor.find({ specialty });

    // Har bir shifokor uchun bo'sh vaqtlarini chiqarish
    const result = doctors.map(doc => {
      const freeSlots = doc.schedule.filter(
        s => !s.isBusy && (!date || s.date === date)  // sana berilmasa hammasi
      );
      return {
        _id:       doc._id,
        fullName:  doc.fullName,
        specialty: doc.specialty,
        room:      doc.room,
        phone:     doc.phone,
        freeSlots,              // bo'sh vaqtlar ro'yxati
        jami:      freeSlots.length
      };
    });

    res.json({ success: true, data: result });
  } catch (err) { res.status(500).json({ message: err.message }); }
};

// Body: { date: "2025-06-20", times: ["09:00","10:00","11:00","14:00"] }
const addSchedule = async (req, res) => {
  try {
    const { date, times } = req.body;
    const doctor = await Doctor.findById(req.params.id);
    if (!doctor) return res.status(404).json({ message: 'Shifokor topilmadi' });

    // Takroriy vaqtlarni qo'shmaslik uchun filtrlash
    const existing = doctor.schedule.filter(s => s.date === date).map(s => s.time);
    const newSlots = times
      .filter(t => !existing.includes(t))
      .map(t => ({ date, time: t, isBusy: false }));

    doctor.schedule.push(...newSlots);
    await doctor.save();

    res.json({ success: true, message: `${newSlots.length} ta vaqt qo'shildi` });
  } catch (err) { res.status(500).json({ message: err.message }); }
};

const Appointment = require('../models/appointment.model');
const Doctor      = require('../models/doctor.model');
const Patient     = require('../models/patient.model');

// ★ ASOSIY: Bemorni shifokorga yozish
// Body: { patientId, doctorId, date: "2025-06-20", time: "09:00" }
const createAppointment = async (req, res) => {
  try {
    const { patientId, doctorId, date, time } = req.body;

    // 1. Shifokorni topish
    const doctor = await Doctor.findById(doctorId);
    if (!doctor) return res.status(404).json({ message: 'Shifokor topilmadi' });

    // 2. Tanlangan vaqt bo'sh ekanligini tekshirish
    const slot = doctor.schedule.find(s => s.date === date && s.time === time && !s.isBusy);
    if (!slot) return res.status(400).json({ message: 'Bu vaqt band yoki mavjud emas' });

    // 3. Qabul yaratish
    const appointment = await Appointment.create({ patient: patientId, doctor: doctorId, date, time });

    // 4. Shifokor vaqtini BAND qilish — boshqa bemor olmasin
    slot.isBusy = true;
    await doctor.save();

    // 5. Bemor statusini yangilash — 1-navbatdan chiqadi
    await Patient.findByIdAndUpdate(patientId, { status: 'yozilgan' });

    // Javobda to'liq ma'lumot
    const result = await Appointment.findById(appointment._id)
      .populate('patient', 'fullName phone illness')
      .populate('doctor',  'fullName specialty room');

    res.status(201).json({ success: true, data: result });
  } catch (err) { res.status(500).json({ message: err.message }); }
};

// Qabullar ro'yxati
// Shifokor: faqat o'zinikini ko'radi
// Admin / Reception: hammasini ko'radi
const getAppointments = async (req, res) => {
  try {
    const filter = {};

    // Shifokor bo'lsa — faqat o'zining qabullarini ko'radi
    if (req.user.role === 'doctor') {
      const doc = await Doctor.findOne({ userId: req.user._id });
      if (doc) filter.doctor = doc._id;
    }

    // ?status=kutmoqda — faqat kutayotganlar
    if (req.query.status) filter.status = req.query.status;

    const list = await Appointment.find(filter)
      .populate('patient', 'fullName phone illness birthDate gender')
      .populate('doctor',  'fullName specialty room')
      .sort({ createdAt: -1 });

    res.json({ success: true, count: list.length, data: list });
  } catch (err) { res.status(500).json({ message: err.message }); }
};

module.exports = { createAppointment, getAppointments };

Middleware
Darvoza — har bir so'rov shu yerdan o'tadi
📄 src/middlewares/auth.middleware.jsyangilash
Nima uchun? Himoyalangan route ga so'rov kelganda — avval protect ishlaydi. Token bor-yo'qligini, to'g'ri ekanini, eskirganini tekshiradi. authorize esa ruxsat berilgan rolni tekshiradi.
const jwt  = require('jsonwebtoken');
const User = require('../models/user.model');

// Token tekshiradi — req.user ga yozadi
// Barcha himoyalangan routelarda ishlatiladi
const protect = async (req, res, next) => {
  try {
    // Header: "Authorization: Bearer eyJhbG..."
    const header = req.headers.authorization;
    if (!header || !header.startsWith('Bearer '))
      return res.status(401).json({ message: "Token yo'q. Avval kiring." });

    const token = header.split(' ')[1];

    // Tokenni tekshirish
    let decoded;
    try {
      decoded = jwt.verify(token, process.env.ACCESS_TOKEN_SECRET);
    } catch (err) {
      // Token eskirsa — frontend /auth/refresh ga boradi
      if (err.name === 'TokenExpiredError')
        return res.status(401).json({ message: 'Token eskirdi', code: 'TOKEN_EXPIRED' });
      return res.status(401).json({ message: 'Token yaroqsiz' });
    }

    // Foydalanuvchini DB dan olish (parol va refreshToken ko'rsatilmaydi)
    const user = await User.findById(decoded.id).select('-password -refreshToken');
    if (!user) return res.status(401).json({ message: 'Foydalanuvchi topilmadi' });

    req.user = user;   // controller da req.user._id, req.user.role ishlatiladi
    next();           // davom etsin
  } catch (err) { res.status(500).json({ message: err.message }); }
};

// Rolni tekshiradi
// Ishlatish: authorize('admin')  →  faqat admin
// Ishlatish: authorize('admin', 'reception')  →  admin yoki reception
const authorize = (...roles) => (req, res, next) => {
  if (!roles.includes(req.user.role))
    return res.status(403).json({ message: `Ruxsat yo'q. Kerakli: ${roles.join(', ')}` });
  next();
};

module.exports = { protect, authorize };
